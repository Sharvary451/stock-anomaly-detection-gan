# Stock Market Anomaly Detection with GANs

This dissertation project used Generative Adversarial Networks to detect anomalies in stock price data from 150+ companies over 10+ years.

## 🔧 Tools & Technologies
- Python, TensorFlow, Pandas, NumPy
- GANs, Matplotlib

## 🧠 Methods
- Preprocessed historical stock data
- Trained GAN to learn "normal" price behavior
- Flagged significant deviations as anomalies

## 📈 Results
- Real-time alerting pipeline created
- Scalable for high-frequency financial data
